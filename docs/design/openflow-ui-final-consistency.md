# OpenFlow UI 最终一致性规范

## 结论

OpenFlow UI-P0～P4 的最终组合在 `feature/ui-release-candidate`、起始 HEAD `24e97d1044028e3706246c39fc042487cf4254ff` 上完成全局一致性收口。UI-P5 的 72 组视觉矩阵、25 项新鲜功能回归、生命周期和可访问性验收未发现需要修改 Renderer 的缺陷，因此本阶段采用 Mode A（docs-only），不制造源代码提交。

本规范描述当前发布候选已经验证的界面契约；它不改变业务状态、事件处理、IPC、配置结构、窗口尺寸或媒体处理参数。

## App Shell

- 左侧主导航保持固定的图标、标签和 52px 点击区域，当前页面使用完整蓝色浅底并提供 `aria-current="page"`。
- 消息中心和设置中心固定在导航底部；760×520、125% 和 150% 下仍位于客户区内，不覆盖三项主导航。
- “格式处理”标签保持单行，主导航标签在全部 72 组矩阵中没有裁切或越界。
- 页面内容与导航隔离；`documentElement` 和 `body` 在全部矩阵中均无页面级横向溢出。
- 页面切换沿用现有状态和路由逻辑，不引入转场、悬浮宠物、鼠标特效或新的应用层覆盖物。

## 页面标题与内容层级

- Daily、Organizer、Format、Settings 使用统一的标题图标容器、20px 页面标题、辅助说明和语义状态区域。
- 内容背景、卡片表面、1px 语义描边、8px 常规圆角和 4px 间距网格保持一致。
- 普通卡片不使用大面积阴影；品牌蓝只用于当前选中、焦点和主操作。
- 成功、处理中/提醒和失败分别使用绿、橙、红语义，同时配合文字、图标、disabled 或 Loader，不只依赖颜色。
- 最大化时内容宽度受控，四页留白节奏一致；760×520 使用一个主要纵向滚动区承载长内容。

## 四页最终行为

### Daily

- 流程步骤、需求导入、目录、素材、尺寸目标、校验和重命名保持一个连续工作流。
- 校验、重命名的当前主操作明确；处理中按钮 disabled 并在按钮内显示 Loader。
- 长中文路径和文件名允许换行或省略，不扩大页面宽度。
- 同名冲突通过保留哨兵并生成递增后缀解决，UI 成功状态与独立磁盘清单共同证明。

### Organizer

- 来源、目标、规则、扫描结果、转移和撤销保持同一主滚动区。
- 一键扫描是当前主操作；无结果、扫描结果、转移完成和撤销反馈具有不同文本状态。
- 图片预览失败使用稳定 fallback；72 组矩阵和新鲜回归中浏览器破图为 0。
- 同名保护、奇觅目录和分辨率目录仍由既有业务逻辑决定，UI-P5 未改动规则。

### Format

- 文件队列和处理动作保持清晰分区；图片与视频队列、混合类型拒绝和不支持类型均有文字反馈。
- 开始处理按钮在真实 3 秒短视频处理中显示按钮内白色 Loader，并阻止重复提交。
- 输出尺寸、质量、格式、动作目录和自定义目录沿用既有处理参数。
- 成功与安全失败状态均进入消息历史；失败不会创建伪输出或损坏原文件。

### Settings

- 常规、账户、工作区、命名模板、快捷键、关于使用稳定的左侧二级导航。
- 760×520 下设置内容在单一主滚动区内；About 真实选中，标题不被导航覆盖。
- 浅色、深色和跟随系统沿用既有持久化；工作区、模板和快捷键在进程重启后重新读取。
- UI-P5 隔离验收快捷键设为 `Ctrl+Alt+O`，实际隐藏、跨应用唤醒和重启后注册均通过。

## 响应式与缩放

验证矩阵为：

- 窗口：760×520、1080×640、最大化；
- 主题：浅色、深色；
- 缩放：100%、125%、150%；
- 页面：Daily、Organizer、Format、Settings。

共 72 组。页面级横向溢出、导航裁切、底部入口裁切、破图均为 0。760×520 的实际客户区为约 744×481；125% 和 150% 的 CSS 视口分别为 595×385 与 496×321，页面仍保持受控滚动，主导航可见。

## 操作反馈与重复保护

- Daily 校验、重命名，Organizer 扫描、转移，Format 处理均保留 disabled/loading 契约。
- Format 最终处理证据来自新生成的 3 秒、1280×720、约 1 MB 测试视频，按钮内 Loader 肉眼可见。
- 消息中心保留本轮需求读取失败、整理撤销、格式成功和格式失败等历史，可追溯到对应操作。
- 成功、失败、空状态和处理中状态均具有文字或结构标识。

## 可访问性

- 从页面正文按 Tab 首先到达“日常”主导航，焦点轮廓为 2px 实线品牌蓝。
- Tab 后按 Enter 激活“整理”，继续 Tab 后按 Space 激活“格式处理”。
- 主导航具有明确名称和当前页语义；消息中心、设置中心、历史、目录选择和删除等图标按钮保留可识别名称。
- 100%、125%、150% 下焦点和主导航均未被容器裁切。

## 发布候选边界

- UI-P5 不修改 Renderer、main、preload、shared、IPC、业务、窗口、配置结构、依赖或 package-lock。
- 旧混合提交 `7b9f3c965d8b7c98936334b3982ab40d3b581ad4` 不是候选祖先。
- Motion Design、页面转场和实验性视觉不属于本地发布候选收口范围。
- 本地候选通过不代表已 Push、已建 PR、已合并或已发布；这些动作需要独立授权和操作文档。
