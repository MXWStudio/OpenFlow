# Scope: 批量命名安全且可恢复

## Hill Position
✓ Done — 预检、有限冲突分配、显式降级和失败项重试均已由文件系统测试验证

## Must-Haves
- [x] 空字段、非法字符、缺失变量、超长名称和无效模板在改动文件前阻断
- [x] 固定文本且无序号的模板遇到冲突时确定性追加后缀，不会无限循环
- [x] 不覆盖已有目标，执行前重新规划并返回逐文件结构化结果
- [x] 自定义规则失效时只提供显式“改用常规”，不静默降级
- [x] 部分失败时保留失败项并支持只重试失败文件
- [x] 主进程配置写入串行化，避免并发 read-modify-write 丢失设置

## Nice-to-Haves (~)
- [ ] ~ 提供跨文件系统的整批事务回滚

## Notes
单项失败会明确返回并可重试，不会卡住整批。配置存储另由单实例锁、进程内串行队列、fsync 临时文件和同目录原子 rename 保护；自动测试覆盖并发变更与替换失败时保留旧配置。
